# SW Web Components Starter

A minimal Vite application using the Web Components API from SuperProvenanceWidgets (SW).

## Run

```bash
npm install
npm run start
```

Open the URL printed by Vite. Interact with the Checkbox and click its footprint to switch provenance views.

During development, `provenance-widgets` is installed from the `feat/v2-v1-compat` GitHub branch. Replace that dependency with `^2.0.0` after SW 2.0 is published to npm.
